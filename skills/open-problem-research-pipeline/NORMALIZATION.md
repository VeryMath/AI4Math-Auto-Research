# Normalization Record

The course edition preserves the submitted `literature-search`,
`literature-analysis`, `literature-proof-framework`, and `qskill` workflows as
four nested, independent Skill entrypoints.

Public-release changes:

- added a package router, interface metadata, MIT license copy, provenance,
  and this normalization record;
- replaced a submitter-specific desktop path with package-relative,
  user-configurable `outputs/` directories;
- made PDF conversion portable by removing a fixed macOS font path and adding
  an optional font setting, and removed an empty unused TeX placeholder;
- added citation, evidence, novelty, and proof-status boundaries;
- excluded `.DS_Store`, `__MACOSX`, generated reports, PDFs, logs, and other
  run outputs from the public package;
- recorded the contributor using the course-wide English-name convention.

The normalization does not merge the four submitted workflows with other
VeryMath skills.
