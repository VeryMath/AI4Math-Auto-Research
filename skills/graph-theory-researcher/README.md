# Graph Theory Researcher

`graph-theory-researcher` supports evidence-aware reading, proof analysis,
question selection, bounded research, and LaTeX/PDF delivery for graph theory.
Its staged workflow contains explicit user gates before question selection,
research, and paper drafting.

Start with [`SKILL.md`](SKILL.md). Load only the references named for the
current stage. For the package's submitted structural checks, run:

```bash
bash scripts/validate-skill.sh
```
